# Editable Draw.io diagrams

Each `.drawio` file contains native Draw.io objects: move a shape, double-click a label, or reconnect an arrow directly in diagrams.net.

| Diagram | Editable source |
| --- | --- |
| SysML requirements | `eventbook-requirements.drawio` |
| Use cases | `eventbook-use-case.drawio` |
| SysML block definition | `eventbook-block-definition.drawio` |
| Deployment architecture | `eventbook-architecture.drawio` |
| Booking sequence | `eventbook-booking-sequence.drawio` |
| Level-1 data flow | `eventbook-data-flow.drawio` |

## Edit online

1. Open the desired `.drawio` file from GitHub and select **Raw**.
2. Copy its raw URL.
3. In [diagrams.net](https://app.diagrams.net/), choose **File → Open From → URL**, paste the raw URL, and select **Open**.
4. Edit the native shapes, then choose **File → Save As** to download the edited `.drawio` source, or export SVG/PNG for the report.

For the linked GitHub copies below, an edit to the repository should be committed before using a new raw URL in diagrams.net.
